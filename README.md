# আইটি রিকুইজিশন ট্র্যাকার

রিকুইজিশন (যা চাওয়া হয়েছে) আর গেট পাস (যা এসেছে) মিলিয়ে দেখার ওয়েব অ্যাপ। কোন আইটেম পুরো এসেছে, আংশিক এসেছে বা আসেনি, তা নিজে থেকেই ধরে দেয়।

**টেক স্ট্যাক:** Node.js 18+ • Express • EJS • PostgreSQL (Neon) • Render (হোস্টিং)

## ১. ফিচার

- **অটো মিলকরণ:** চাহিদা, প্রাপ্ত পরিমাণ ও আইটেমের নামের মিল দেখে স্ট্যাটাস ঠিক হয় (মিলেছে / আংশিক / মিলেনি / অপেক্ষমান)। চাইলে হাতে স্ট্যাটাস ও নোট দেওয়া যায়।
- **সারসংক্ষেপ পেজ:** মিলে যাওয়ার হার, স্ট্যাটাস অনুযায়ী ভাগ (ক্লিক করলে ওই এন্ট্রির তালিকা), চাহিদা বনাম প্রাপ্ত, ১৪ দিনের ট্রেন্ড চার্ট।
- **সার্চ, ফিল্টার ও পেজিনেশন:** আইটেম, রিকুইজিশন নং বা গেট পাস নং দিয়ে খোঁজা যায়।
- **গেট পাসের ছবি আপলোড:** সর্বোচ্চ ২MB, ছবি ডাটাবেজেই জমা থাকে।
- **রিপোর্ট:** প্রিন্ট-ফ্রেন্ডলি পেজ (ব্রাউজার থেকে "Save as PDF" করলে বাংলাসহ PDF হয়) ও Excel এক্সপোর্ট।
- **CSV বাল্ক ইম্পোর্ট:** একসাথে অনেক এন্ট্রি যোগ করা যায়।
- **অ্যাক্টিভিটি লগ:** কে কখন কী যোগ, বদল বা মুছেছে তার ইতিহাস।
- **রোল:** `admin` ও `staff`। শুধু admin এন্ট্রি মুছতে ও স্টাফ ম্যানেজ করতে পারে।
- **রেসপন্সিভ ডিজাইন:** ডেস্কটপে সাইডবার, মোবাইলে নিচের নেভিগেশন।
- **নিরাপত্তা:** CSRF টোকেন, লগইনে rate limit, Helmet + CSP, secure cookie, bcrypt পাসওয়ার্ড।

## ৩. শুরুর আগে যা লাগবে

| [Neon](https://neon.tech) অ্যাকাউন্ট | PostgreSQL ডাটাবেজ |

| [Render](https://render.com) অ্যাকাউন্ট | অ্যাপ লাইভ করতে |

`node -v` লিখে Node-এর ভার্সন দেখে নিন।

## ৪. Environment Variables

| নাম | আবশ্যক? | বিবরণ |
|---|---|---|
| `DATABASE_URL` | হ্যাঁ | Neon-এর Connection string, `?sslmode=require` সহ |
| `SESSION_SECRET` | production-এ হ্যাঁ | লম্বা র‍্যান্ডম লেখা। এটা না থাকলে production-এ সার্ভার চালুই হয় না |
| `NODE_ENV` | production-এ হ্যাঁ | `production` দিন |
| `PORT` | না | ডিফল্ট `3000`। Render নিজেই সেট করে দেয় |

`SESSION_SECRET` বানাতে টার্মিনালে এটা চালান:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## ৫. লোকাল মেশিনে চালানো

**১. কোড নামিয়ে ডিপেন্ডেন্সি ইনস্টল করুন**

```bash
git clone <আপনার-রিপোর-লিংক>
cd it-requisition-tracker
npm install
```

**২. Neon-এ ডাটাবেজ বানান** (ধাপ [৭.১](#71-neon-এ-ডাটাবেজ-বানান) দেখুন) এবং Connection string কপি করুন।

**৩. `.env` ফাইল বানান**

```bash
cp .env.example .env
```

`.env` খুলে নিজের মান বসান:

```
DATABASE_URL=postgresql://user:password@ep-xxxx.region.aws.neon.tech/neondb?sslmode=require
SESSION_SECRET=এখানে-লম্বা-র‍্যান্ডম-লেখা
PORT=3000
NODE_ENV=development
```

**৪. অ্যাপ চালু করুন**

```bash
npm start
```

প্রথমবার চালু হলে অ্যাপ নিজেই সব টেবিল বানিয়ে নেয়। এরপর ব্রাউজারে `http://localhost:3000` খুলুন।

**৫.** এবার [প্রথম অ্যাডমিন তৈরি](#৬-প্রথম-অ্যাডমিন-তৈরি-বাধ্যতামূলক) করুন, নইলে লগইন করার মতো কোনো অ্যাকাউন্ট থাকবে না।

## ৬. প্রথম অ্যাডমিন তৈরি (বাধ্যতামূলক)

এই অ্যাপে **নিজে নিজে রেজিস্ট্রেশন বন্ধ**। `/register` খুললে লগইন পেজে পাঠিয়ে দেয়। তাই প্রথম admin স্ক্রিপ্ট দিয়ে বানাতে হয়।

`.env`-এ `DATABASE_URL` থাকা অবস্থায় প্রজেক্ট ফোল্ডারে চালান:

```bash
node create-admin.js "আপনার নাম" you@example.com আপনার-পাসওয়ার্ড
```

- পাসওয়ার্ড কমপক্ষে ৬ অক্ষরের হতে হবে।
- স্ক্রিপ্টটি Neon-এর ডাটাবেজে সরাসরি লেখে, তাই লাইভ ডেপ্লয়ের ডাটাবেজের জন্যও নিজের কম্পিউটার বা ফোনের টার্মিনাল (যেমন Termux বা GitHub Codespaces) থেকে চালালেই হয়। Render-এর ফ্রি প্ল্যানে শেল পাওয়া যায় না।
- ওই ইমেইলে আগে থেকে অ্যাকাউন্ট থাকলে স্ক্রিপ্টটি সেটাকে admin বানিয়ে নতুন পাসওয়ার্ড বসায়।
- একবার লগইন করার পর বাকি স্টাফ **অ্যাডমিন প্যানেল (`/admin/users`)** থেকে যোগ করুন।

## ৭. লাইভ ডেপ্লয়: Neon + Render

### ৭.১ Neon-এ ডাটাবেজ বানান

1. [neon.tech](https://neon.tech)-এ লগইন করে **New Project** চাপুন। নাম দিন যেমন `it-tracker`।
2. প্রজেক্ট তৈরি হলে ড্যাশবোর্ডের **Connect** বাটনে চাপুন।
3. **Connection string** কপি করে নিরাপদ জায়গায় রাখুন। দেখতে এমন:
   `postgresql://user:password@ep-xxxx.region.aws.neon.tech/neondb?sslmode=require`
4. টেবিল আলাদা করে বানাতে হবে না। অ্যাপ প্রথমবার চালু হলেই বানিয়ে নেয়।

### ৭.২ GitHub-এ কোড তুলুন

কম্পিউটার থেকে:

```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/<ইউজারনেম>/<রিপো-নাম>.git
git push -u origin main
```

ফোন থেকে হলে GitHub অ্যাপ বা ব্রাউজারে **Add file → Upload files** দিয়ে ফাইল তুলতে পারেন।

> ⚠️ **`.env` ফাইল কখনো GitHub-এ তুলবেন না।** এতে আপনার ডাটাবেজের পাসওয়ার্ড আছে। `.gitignore` কমান্ড-লাইন `git` থেকে এটা আটকায়, কিন্তু ব্রাউজারের "Upload files" এটা আটকায় না। আপলোডের আগে `.env` ও `node_modules` ফোল্ডার বাদ দিন।

### ৭.৩ Render-এ ওয়েব সার্ভিস বানান

1. Render-এ **New +** → **Web Service** → আপনার GitHub রিপো সিলেক্ট করুন।
2. এই মানগুলো দিন:

   | ঘর | মান |
   |---|---|
   | Runtime / Language | Node |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance type | Free |

3. **Environment Variables** যোগ করুন:

   | Key | Value |
   |---|---|
   | `DATABASE_URL` | Neon-এর Connection string (পুরোটা) |
   | `SESSION_SECRET` | [ধাপ ৪-এর কমান্ডে বানানো লেখা](#৪-environment-variables) |
   | `NODE_ENV` | `production` |

4. **Advanced** অংশে **Health Check Path** হিসেবে `/healthz` দিন।
5. **Create Web Service** চাপুন। কয়েক মিনিট পর `https://আপনার-নাম.onrender.com` লিংক পাবেন।

### ৭.৪ প্রথম অ্যাডমিন বানান

ডেপ্লয় শেষ হলে [ধাপ ৬](#৬-প্রথম-অ্যাডমিন-তৈরি-বাধ্যতামূলক)-এর কমান্ড চালান, যেখানে `DATABASE_URL` হবে Neon-এর সেই একই স্ট্রিং। তারপর লাইভ লিংকে গিয়ে লগইন করুন।

### ৭.৫ কোড বদলালে আবার ডেপ্লয়

`main` ব্রাঞ্চে `git push` করলে Render নিজে থেকেই নতুন ভার্সন ডেপ্লয় করে (Auto-Deploy চালু থাকলে)। ডাটাবেজের কিছু করতে হয় না, `schema.sql` প্রতিবার নিরাপদে চলে।

## ৮. বিকল্প: Docker বা অন্য হোস্ট

**Docker (Railway, Fly.io, নিজের VPS ইত্যাদি):**

```bash
docker build -t it-requisition-tracker .
docker run -p 3000:3000 --env-file .env it-requisition-tracker
```

`.env`-এ ওই তিনটি ভেরিয়েবল (`DATABASE_URL`, `SESSION_SECRET`, `NODE_ENV=production`) থাকতে হবে। হোস্ট HTTPS প্রক্সির পেছনে থাকলে অ্যাপ সেটা নিজেই বুঝে নেয় (`trust proxy` সেট করা আছে)।

**Docker ছাড়া VPS-এ:** Node 18+ ইনস্টল করে `npm install --omit=dev`, তারপর `NODE_ENV=production` ও বাকি ভেরিয়েবল সেট করে `npm start`। দীর্ঘদিন চালাতে `pm2` বা `systemd` ব্যবহার করুন।

## ১০. ব্যবহারকারী ব্যবস্থাপনা ও স্ক্রিপ্ট

অ্যাডমিন হিসেবে লগইন করলে সাইডবারে **স্টাফ ম্যানেজমেন্ট** দেখা যায়। সেখান থেকে স্টাফ যোগ, পাসওয়ার্ড বদল, রোল পরিবর্তন ও অ্যাকাউন্ট মোছা যায়।

ওয়েবে ঢুকতে না পারলে টার্মিনালের স্ক্রিপ্ট কাজে লাগবে (সবগুলোর জন্য `.env`-এ `DATABASE_URL` লাগে):

| কাজ | কমান্ড |
|---|---|
| সব ইউজার ও রোল দেখা | `node list-users.js` |
| পাসওয়ার্ড রিসেট | `node reset-password.js you@example.com নতুন-পাসওয়ার্ড` |
| নতুন admin বানানো বা কাউকে admin করা | `node create-admin.js "নাম" you@example.com পাসওয়ার্ড` |

নিজে নিজে অ্যাকাউন্ট খোলার সুযোগ নেই, তাই পাসওয়ার্ড ভুলে গেলে admin বদলে দেবেন অথবা `reset-password.js` চালাবেন।

## ১১. CSV ইম্পোর্টের ফরম্যাট

সাইডবারের **CSV ইম্পোর্ট** পেজে ফাইল দিন। প্রথম সারিতে কলামের নাম থাকতে হবে। শুধু `item_name` আবশ্যক, বাকিগুলো ঐচ্ছিক। তারিখ লিখুন `YYYY-MM-DD` ফরম্যাটে।

```csv
item_name,req_no,req_date,description,req_qty,unit,gatepass_no,gatepass_date,gatepass_item_name,received_qty,received_date,sender_name
ল্যাপটপ,REQ-2026-001,2026-09-01,Core i5 8GB,5,পিস,GP-1123,2026-09-10,ল্যাপটপ Dell,5,2026-09-10,মিস্টার সাহীর
```

আইটেমের নাম খালি থাকা সারি বাদ পড়ে; ইম্পোর্ট শেষে কয়টি যোগ ও কয়টি বাদ গেল তা দেখানো হয়।

## ১২. নিরাপত্তা

- **`.env` কখনো কমিট বা আপলোড করবেন না।** ভুলে GitHub-এ চলে গেলে Neon ড্যাশবোর্ড থেকে ডাটাবেজের পাসওয়ার্ড রিসেট করে Render-এ নতুন `DATABASE_URL` বসান।
- production-এ `SESSION_SECRET` বাধ্যতামূলক; একবার বদলালে সবাই লগআউট হয়ে যাবে।
- লগইনে প্রতি IP থেকে ১৫ মিনিটে সর্বোচ্চ ১০টি চেষ্টা করা যায়।
- সব ফর্মে CSRF টোকেন আছে; Helmet ও Content-Security-Policy চালু।
- ফাইল আপলোড শুধু ছবি ও CSV, ছবির সীমা ২MB।
- নতুন ইউজার শুধু admin যোগ করতে পারে।

## ১৪. সমস্যা হলে কী করবেন

| সমস্যা | কারণ ও সমাধান |
|---|---|
| সার্ভার চালু হয়েই বন্ধ, লগে `SESSION_SECRET পরিবেশ ভেরিয়েবল সেট করা নেই` | `NODE_ENV=production` থাকলে `SESSION_SECRET` লাগে। Render-এর Environment-এ যোগ করুন |
| `password authentication failed` বা `ENOTFOUND` | `DATABASE_URL` ভুল বা অসম্পূর্ণ। Neon-এর **Connect** থেকে আবার পুরো স্ট্রিং কপি করুন, শেষে `?sslmode=require` আছে কিনা দেখুন |
| `connection terminated` বা প্রথম কোয়েরিতে দেরি | Neon-এর ফ্রি ডাটাবেজ কিছুক্ষণ অলস থাকলে ঘুমিয়ে যায়। কয়েক সেকেন্ড পর আবার চেষ্টা করুন। বারবার হলে Connect ডায়ালগ থেকে Direct (non-pooled) স্ট্রিং ব্যবহার করে দেখুন |
| লগইন করার পরও আবার লগইন পেজে ফিরে যায় | Render বা প্রক্সির পেছনে `NODE_ENV=production` না দিলে কুকি ঠিকমতো সেট হয় না। ভেরিয়েবলটি দিন ও ব্রাউজারের কুকি মুছে আবার চেষ্টা করুন |
| "অনেকবার চেষ্টা করা হয়েছে" | লগইনে rate limit ধরেছে। ১৫ মিনিট অপেক্ষা করুন |
| লগইন করার অ্যাকাউন্টই নেই | রেজিস্ট্রেশন বন্ধ। [ধাপ ৬](#৬-প্রথম-অ্যাডমিন-তৈরি-বাধ্যতামূলক)-এর `create-admin.js` চালান |
| পাসওয়ার্ড ভুলে গেছি | `node reset-password.js ইমেইল নতুন-পাসওয়ার্ড` |
| Render-এ প্রথম ভিজিটে ২০–৩০ সেকেন্ড লাগে | ফ্রি ওয়েব সার্ভিস অলস থাকলে ঘুমায়। এটা স্বাভাবিক |
| `relation "session_pkey" already exists` | এই প্রজেক্টের `schema.sql` এটা সামলায়। নিজের টেবিলে হাত দিয়ে থাকলে `it_session` টেবিলটি মুছে অ্যাপ আবার চালান |
| `EADDRINUSE` (লোকালে) | ৩০০০ পোর্ট ব্যস্ত। `.env`-এ `PORT=3001` দিন |
| ছবি আপলোড হচ্ছে না | ফাইল ২MB-র বেশি হলে বা ছবি না হলে আটকায়। ছোট করে আবার দিন |
| ডাটাবেজের জায়গা ভরে যাচ্ছে | ছবি ডাটাবেজেই জমা হয়। অপ্রয়োজনীয় ছবি সরান এবং Neon ড্যাশবোর্ডে স্টোরেজ ব্যবহার দেখুন |

কিছুতেই না মিললে Render-এর **Logs** ট্যাবে আসল এরর মেসেজ থাকে। সেটা দেখে ওপরের টেবিলে মেলান।
